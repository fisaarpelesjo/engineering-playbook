# OWNER_STANDING_ORDERS.md

Ordens permanentes do proprietario deste repositorio. Cada item cita a **fonte** e, quando
existe, a **palavra literal** dele entre aspas. Nenhuma ordem entra por paráfrase de um agente
— sem fonte e sem citação, não é ordem permanente, é interpretação, e interpretação não vai
para este arquivo.

Este registro começa vazio. Nenhuma ordem abaixo é real; a única linha do arquivo é o exemplo
comentado que mostra a forma.

Legenda das fontes:
- `CHAT` — trecho literal de uma conversa com o proprietário, citado com a data
- `DOC` — outro documento do repositório que registra a ordem, citado por caminho
- `MEM` — memória automática do agente, onde a ordem literal foi registrada na data indicada
